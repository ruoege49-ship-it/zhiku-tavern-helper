## 共享上传

共享页右上角「＋ 上传」可填写名称、署名、画师串、标签和说明，并附上最多 6 张例图。上传后自动打开「我分享的」，署名会显示在共享卡片上并记住供下次使用。

已内置共享服务器地址，无需邀请码。原有自定义服务器地址优先使用。多用户可同时浏览、上传和保存；自己的 NovelAI Key 仍由自己在酒馆内配置。
